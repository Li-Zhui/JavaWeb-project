一、SQL
    1.SQL：
        一门操作关系型数据库的编程语言，定义操作所有关系型数据库的统一标准。

    2.分类：
      分类        全称                              说明
      DDL   Data Definition Language    数据定义语言，用来定义数据库对象（数据库，表，字段)

      DML   Data Manipulation Language  数据操作语言，用来对数据库表中的数据进行增删改

      DQL   Data Query Language         数据查询语言，用来查询数据库中表的记录

      DCL   Data Control Language       数据控制语言，用来创建数据库用户、控制数据库的访问权限

    3.特点
        3.1 不区分大小写
        3.2 分号‘;‘代表结束
        3.3 在一个数据库服务器中，数据库的名字不能重复
        3.4 在sql语句中“”和‘’都可以使用

二、DDL（一定注意分号;）
    1.操作语法
      --查询所有数据库
        show databases;
      --查询当前数据库
        select database();
      --使用/切换数据库
        use 数据库名;
      --创建数据库
        create database[if not exists］ 数据库名[default charset utf8mb4];
      --删除数据库
        drop database[if exists］ 数据库名;

        注意：上述语法中的database，也可以替换成 schema。
        如：create schema dbo1；MySQL8版本中，默认字符集为utf8mb4。

    2.DDL-表结构-创建
        2.1 创建表的语法:
          create table 表的名字(
            字段1 字段类型 [约束] [comment字段1注释],
            ......
            字段2 字段类型 [约束] [comment字段2注释]
          )[comment 表注释];

        2.2 约束
            2.2.1 是什么？
                约束是作用于表中字段上的规则，用于限制存储在表中的数据
            2.2.2 目的：
                保证数据库中数据的正确性、有效性和完整性。
            2.2.3 常见约束
                 约束              描述                                      关键字
                非空约束    限制该字段值不能为null                           not null
                唯一约束    保证字段的所有数据都是唯一、不重复的                 unique
                主键约束    主键是一行数据的唯一标识，要求非空且唯一            primary key
                默认约束    保存数据时，如果未指定该字段值，则采用默认值          default
                外键约束    让两张表的数据建立连接，保证数据的一致性和完整性      foreign key
            2.2.4 注意：
                    一张表中最多只能有一个主键约束。
                    外键约束至少两张表。
            2.2.5 如何实现主键自增的效果呢？
                    定义主键的时候指定关键字 auto_increment
            2.2.6 一个字段上是否可以添加多个约束？
                    可以，多个约束之间使用空格分开

    4.DDL-表结构-查询、修改、删除
        4.1 表结构的查询、修改、删除相关语法如下:
          show tables;
                                         -- 查询当前数据库的所有表
          desc 表名;
                                         -- 查询表结构
          show create table 表名;
                                         -- 查询建表语句
          alter table 表名 add 字段名 类型（长度）［comment 注释］[约束];

          alter table 表名 modify 字段名 新数据类型（长度）;

          drop  table [if exists］表名;
                                          -- 删除表
        4.2 注意：在删除表时，表中的全部数据也会被删除。


三、DML
    1.概述：
        OML英文全称是Data Manipulation Language(数据操作语言），
        用来对数据库中表的数据记录进行增、删、改操作。

    2.对应
        添加数据(INSERT)
        修改数据(UPDATE)
        删除数据(DELETE)
            （删除一个字段为修改操作，这里的DELETE为删除一条数据）

    3.DML-insert
        -- 指定字段添加数据（字段与值一一对应）
            insert into 表名（字段名1,字段名2） values（值1,值2）;
        -- 全部字段添加数据（省略字段名）
            insert into 表名 values（值1,值2, ...）;
        -- 批量添加数据（指定字段）
            insert into 表名（字段名1,字段名2） values（值1,值2）,（值1,值2);
        -- 批量添加数据（全部字段）
            insert into 表名 values（值1,值2, ...），（值1,值2, ...）;

    4.DML-update
        4.1 语句
            -- 修改数据
                update 表名 set 字段名1 = 值1，字段名2 = 值2where条件］；
        4.2 注意：
            修改语句的条件可以有，也可以没有，如果没有条件，则会修改整张表的所有数据。

   5.DML-delete
        4.1 语句
            -- 删除数据
                delete from 表名[where条件];
        4.2 注意：
            4.2.1 DELETE语句的条件可以有，也可以没有，如果没有条件，
                    则会删除整张表的所有数据。
            4.2.2 DELETE语句不能删除某一个字段的值(如果要操作，可以
                    使用UPDATE，将该字段的值置为NULL)。


四、DQL
    1.概述
        DQL英文全称是Data Query Language(数据查询语言），用来查询数据库表中的记录。
        关键字：SELECT

    2.完整的DQL语句语法：
          查询数据-select
            2.1 基本查询
              select
                    字段列表
              from
                    表名列表

            2.2 条件查询
              where
                    条件列表

            2.3 分组查询
              group by
                    分组字段列表
              having
                    分组后条件列表

            2.4 排序查询
              order by
                    排序字段列表

            2.5 分页查询
              limit
                    分页参数

    3.基本查询
        3.1 语法
            -- 查询多个字段
                select 字段1，字段2，字段3 from 表名;
            -- 查询所有字段（通配符）
                select * from 表名;
            -- 为查询字段设置别名（别名如果没有空格则可以不加‘’号），as关键字可以省略
                select 字段1［as 别名1］,字段2［as 别名2］] from 表名;
            -- 去除重复记录
                select distinct 字段列表表 from 表名；
           注意：*号代表查询所有字段，在实际开发中尽量少用(不直观、影响效率)

        3.2 小结：
            3.2.1 基本查询语法?
                    select 字段列表 from 表名
            3.2.2 如何为查询返回的字段设置别名?
                    字段名 [as] 别名
            3.2.3 如何去除查询返回的重复记录？
                    distinct

    4.条件查询
        4.1 语法
            -- 条件查询
                select 字段列表 from 表名
                    where 条件列表
            注意：between ... and ...  必须左小右大

        4.2 小结：
            4.1 如何进行null值的判断?is null ，is not null
            4.2 模糊匹配中的通配符?%（任意个字符），_（一个字符）
            4.3 如何组装多个查询条件？andor

    5.分组查询
        5.1 聚合函数：
                将一列数据作为一个整体，进行纵向计算。
                    函数      功能       用法
                    count   统计数量    count(字段) count(*) count(常量)
                   （优先使用*因为在MySQL底层有优化，性能最高，其次常量，因为常量与*性能差不多）
                    max     最大值
                    min     最小值
                    avg     平均值
                    sum     求和
             注意：a．null值不参与所有聚合函数的运算
                  b．统计数量可以使用：count(*)count(字段)count（常量），
                     推荐使用count（*）

        5.2 语法
            5.2.1 -- 分组查询
                select 字段列表 from 表名 [where 条件列表]
                    group by 分组字段名 [having 分组后过滤条件];

            5.2.2 where与having的区别:
                a．执行时机不同(where > group by > having)：
                              where是分组之前进行过滤，不满足where条件，不参与分组;
                              而having是分组之后对结果进行过滤。
                b．判断条件不同：
                              where不能对聚合函数进行判断，而having可以。

        5.3 注意：
            5.3.1 分组之后，查询的字段一般为聚合函数和分组字段，查询其他字段无任何意义。
            5.3.2 执行顺序：where > 聚合函数 > having

    6.DQL-排序查询
        6.1 语法
            -- 排序查询
                select 字段列表 from 表名 [where 条件列表] [group by 分组字段名 having 分组后过滤条件]
                    order by 排序字段 排序方式;

        6.2 排序方式
                6.2.1 方式：
                        升序（asc）,降序（desc）；默认为升序asc，是可以不写的。
                6.2.2 注意：
                        如果是多字段排序，当第一个字段值相同时，才会根据第二个字段进行排序。

    7，分页查询（不同的数据库有不同的分页查询语法，以下为MySQL的分页查询）
        7.1 语法
            -- 排序查询
            select 字段 from 表名 [where 条件] [group by 分组字段 having 过滤条件] [order by 排序字段]
                limit 起始索引,查询记录数;

        7.2 说明：
            7.2.1 起始索引从0开始（即第一条数据的索引是0）
            7.2.2 分页查询是数据库的方言，不同的数据库有不同的实现，MySQL中是LIMIT
            7.2.3 如果起始索引为θ，起始索引可以省略，直接简写为 limit 1θ。

        7.3 小结：
            DQL语句中的分页查询
                语法：limit 起始索引,每页展示记录数
                注意：项目开发中，前端传递过来的是页码，需要转换为起始索引
                公式：起始索引 = （页码-1）＊每页展示记录数
