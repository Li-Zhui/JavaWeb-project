一、什么是MyBatis
    1.MyBatis是一款优秀的持久层（dao层）框架，用于简化JDBC的开发。

    2.MyBatis本是Apache的一个开源项目iBatis，2010年这个项目由apache迁移到了google code，
      并且改名为MyBatis。2013年11月迁移到Github。

    3.官网:
        https://mybatis.org/mybatis-3/zh_CN/index.htm


二、使用Mybatis查询所有用户数据
    1.准备工作：
        1.1 创建SpringBoot工程、引入MyBatis相关依赖
        1.2 准备数据库表user、实体类User
        1.3 配置Mybatis（在application.properties中数据库连接信息）
                数据库连接信息四要素：
                    a.数据库连接的url地址
                        例如：spring.datasource.url=jdbc:mysql://localhost:3306/web
                    b.数据库驱动的全类名
                        例如：spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
                    c.用户名
                        例如：spring.datasource.username=root
                    d.密码
                        例如：spring.datasource.password=1234

    2.编写MyBatis程序：编写MyBatis的持久层接口，定义SQL（注解/XML）
        2.1 命名：
                @Mapper
                public interface ...Mapper{
                    @Select("查询语句")
                    public List<User> findAll();

                        //findAll()一旦运行就会自动执行Select注解中的这条查询语句
                        //并且将查询返回的结果自动封装到这个方法的返回值中
                        //每一条数据都会封装到User对象中，多个用户对象会自动封装到这个List集合中
                }

        2.2 注解解析
                2.2.1 @Mapper
                        应用程序在运行时，会自动的为该接口创建一个实现类对象（代理对象）
                        并且会自动将该实现类对象存入IOC容器 - bean 。
                2.2.2 @SpringBootTest
                        SpringBoot单元测试的注解 - 当前测试类中的测试方法运行时，
                        会启动springboot项目 - 一旦启动IOC容器就创建好了

        2.3 提示：
            MyBatis的持久层接口命名规范为 XxxMapper，也称为 Mapper接口。

        2.4注意：
            测试类所在包需要与引导类包名相同（或放在引导类所在包的子包下）
                即SpringbootMybatisQuickstartApplicationTests
                和SpringbootMybatisQuickstartApplication
                的包名要相同（都为com.itheima）

四、JDBC VS Mybatis
    1.JDBC
        1.1 硬编码：
                代码都写死了，url、用户名、密码等一旦变动，就需要频繁改动
        1.2 查询繁琐：
                查询结果的解析十分繁琐（当字段很多时，一个个字段解析很麻烦）
        1.3 资源浪费：
                频繁地获取连接、释放连接 导致 资源浪费、性能降低

    2.Mybatis
        2.1 解决硬编码：
                不用找每一个java代码去改，直接去配置文件改就行，
                并且java代码改了之后需要重新编译才能执行，而改配置文件不需要编译。
        2.2 解决查询繁琐：
                Mybatis自动地将结果解析，并将其封装到List集合中去。
        2.3 解决资源浪费：
                spring.datasource这个配置底层使用了数据库连接池。


五、Mybatis-数据库连接池
    1.认识
        1.2 是什么
                数据库连接池是个容器，负责分配、管理数据库连接（Connection）。
        1.2 作用
                它允许应用程序重复使用一个现有的数据库连接，而不是再重新建立一个。
        1.3 性质
                释放（归还给连接池）空闲时间超过最大空闲时间的连接，来避免因为没有释放连接而引起的数据库连接遗漏。
        1.4 优势：
                资源重用
                提升系统响应速度
                避免数据库连接遗漏（有些客户端获取到连接时让这个连接一直处于空闲状态）

    2.实现数据库连接池
        2.1 标准接口：
                DataSource
            官方(sun)提供的数据库连接池接口，由第三方组织实现此接口。
            功能（方法）：从数据库连接池中获取一个连接     Connection getConnection() throws SQLException;
        2.2 市面上数据库连接池产品：
            2.2.1 目前不常用：
                C3P0
                DBCP
            2.2.2 企业常用：
                a. Druid（德鲁伊连接池）
                        Druid连接池是阿里巴巴开源的数据库连接池项目
                        功能强大，性能优秀，是JaVa语言最好的数据库连接池之一
                b. Hikari （追光者连接池 SpringBoot默认自带）

六、MyBatis--增删改查操作--删除操作
    1.删除用户-delete
        需求：
            根据ID删除用户信息
        SQL；
            delete from user where id =5；
    2.@Delete（sql语句注解）
        @Delete（"delete from user where id = #{id}")
        public void deleteById(Integer id);
            2.1 #{}
                这个占位符表示表示最终里面的值是要被替代掉的
            2.2 deleteById中的id传进来是多少最终被替代的就是多少
                最终在执行时#{}会被替代成 ‘？’ 这个占位符，即最终成为一个预编译sql

    3.注意：
        DML语句执行完毕的返回值，表示该DML语句执行完毕影响的行数。

    4.MyBatis中的 # 号与 $ 号：
       符号                        说明                                    场景                       优缺点
      #{...}       占位符。执行时，会将#{。..}替换为？，生成预编译SQL         参数值传递                安全、性能高高 (推荐)
      ${...]       拼接符。直接将参数拼接在SQL语句中，存在SQL注入问题     表名、字段名动态设置时使用       不安全、性能低


七、MyBatis--增删改查--增加操作
    1.新增用户-insert
        需求：
            添加一个用户
        SQL:
            insert into user(username,password,name,age） values('zhouyu','123456','周瑜',20);

    2.Mapper接口：
        2.1 写死的代码：
            @Insert("insert into user(username,password,name,age)values('zhouyu',，'123456'，‘周瑜'，20)")
            public void insert();
        2.2 正常代码（将各个属性传入到一个User对象中去）：
            @Insert("insert into user(username,password,name,age) values(#{username},#{password},#{name},#{age})")
            public void insert(User user);


八、MyBatis--增删改查--修改操作
    1.修改用户-update
        需求：
            根据ID更新用户信息
        SQL:
            update user set username = 'zhouyu'，password = '123456'，name ='周瑜'，age = 20 where id = 1;

    2.Mapper接口:
      @Update("update user set username=#{username}，password=#{password}，name=#{name}，age=#{age} where id=#{id}")
      public void update(User user);
